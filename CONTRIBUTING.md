# Contributing to PlantGuide

Welcome! PlantGuide is a plant identification and care guide platform.

## Good First Issues
Look for issues labeled good first issue for newcomer-friendly tasks.

## Setup
1. Fork the repo
2. Clone your fork
3. Install: pip install -r requirements.txt
4. Test: pytest

## PR Process
1. Create feature branch from master
2. Make changes + tests
3. Ensure CI passes
4. Open a PR with clear description

## Code Style
- PEP 8 for Python
- Type hints encouraged
- Docstrings for public API

## Questions?
Open an issue or comment on an existing one. We are here to help!
