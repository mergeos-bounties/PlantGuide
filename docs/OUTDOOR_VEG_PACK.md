# Outdoor / vegetable pack (tropical & subtropical)

Issue [#22](https://github.com/mergeos-bounties/PlantGuide/issues/22) adds outdoor edible
care profiles with explicit `climate_notes` for tropical/subtropical gardens.

| ID | Common name |
| --- | --- |
| `bitter_melon` | Bitter Melon |
| `eggplant_purple` | Purple Eggplant |
| `ginger_culinary` | Culinary Ginger |
| `turmeric` | Turmeric |
| `malabar_spinach` | Malabar Spinach |
| `lemongrass_citronella` | Citronella Lemongrass |
| `okra_abelmoschus` | Okra |
| `ipomoea_aquatica` | Water Spinach (Kangkong) |
| `capsicum_jalapeno` | Jalapeño Chili |
| `allium_fistulosum` | Bunching Onion (Scallion) |

Existing tomato / bird’s-eye chili / spearmint cards remain in the catalog.

```powershell
plantguide care show -s okra_abelmoschus
plantguide care show -s ipomoea_aquatica
```
